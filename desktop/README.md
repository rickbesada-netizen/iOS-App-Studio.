# Windows Studio
Download iOS-App-Studio.exe from GitHub Releases after a successful Windows build. This is a portable executable, not a signed installer. Projects are stored in LocalAppData. Create a project, design up to five text/navigation screens, generate Dart, edit code, preview layout, export, or push to an existing GitHub repository. GitHub credentials are session-only. Use a token restricted to your intended app repository with Contents, Workflows and Actions write permissions. GitHub may require additional authorization for workflow files. Unsigned builds are not installable on iPhone. For signed builds, connect the generated repository to Codemagic and configure Apple credentials there. The desktop preview is not an iOS simulator. AI generation, custom icons, automatic Apple metadata submission and automatic updates are not implemented in this version.
